# Winter Crops and Fallow fields Analsysis in Central Valley CA
Scripts to run analysis and visualize results for the PPIC Fallow Lands vs Winter Wheat ET Analysis

The analysis uses OpenET ensemble data v2.0 and updated geodatabase

Results from the analysis are presented in: 'SGMA-Ready Crops as a Low Water Alternative to Fallowing'
https://www.ppic.org/publication/sgma-ready-crops-as-a-low-water-alternative-to-fallowing/
